# Сканы: что изменилось

Твой PDF — картинки без текстового слоя. Парсер переписан: страницы рендерятся
в JPEG и уходят в Claude Vision, который распознаёт текст **и сразу** режет его
на Aufgaben/Teilaufgaben. Tesseract не нужен, системных установок нет.

## Настройка (один раз)

```powershell
pip install pymupdf anthropic
setx ANTHROPIC_API_KEY "sk-ant-..."
```

Ключ берётся на console.anthropic.com → API Keys. **Перезапусти терминал** после
`setx`, иначе переменная не подхватится.

Проверка, что всё на месте:

```powershell
python parse_exam.py --list-models
```

Список моделей выведется — значит ключ работает. Если нужной модели в списке нет,
подставь актуальный ID через `--model`.

## Запуск

```powershell
# 1. холостой прогон: рендер и пути без вызовов API
python parse_exam.py --aufgaben "raw/AP1-2026-F.pdf" --exam-id ap1-2026-fs --dry-run

# 2. боевой
python parse_exam.py `
  --aufgaben  "raw/AP1-2026-F.pdf" `
  --loesungen "raw/AP1-2026-F-LOE.pdf" `
  --exam-id   ap1-2026-fs `
  --title     "Einrichten eines IT-gestützten Arbeitsplatzes" `
  --part AP1 --year 2026 --season Frühjahr --minutes 90
```

Перед стартом печатается оценка стоимости. 12 страниц ≈ $0.35–0.50.

## Кэш

Каждая страница кэшируется в `.cache/` по хешу картинки. Повторный запуск —
бесплатный и мгновенный. Это важно: сборку JSON придётся прогонять несколько раз,
пока настроишь параметры, и платить за это дважды не нужно.

- `--offline` — собрать только из кэша, без сети
- удалить `.cache/` — заставить перечитать заново

## Что делать после

`exams/<id>.report.json` теперь содержит два раздела:

- **uncertain** — места, где модель не уверена в символе. В тексте они помечены
  `<?>` и в интерфейсе подсвечены жёлтым. **Сверь их с PDF руками.** Это в первую
  очередь цены, объёмы, IP-адреса, маски подсети.
- **warnings** — не найдены баллы или Lösung.

Правь `exams/<id>.json` напрямую, кэш при этом не трогается.

## Про надёжность

Vision-модель распознаёт текст очень хорошо, но это не детерминированный OCR:
на плохом скане она может ошибиться в цифре и не пометить это. Поэтому:

- температура 0, промпт запрещает додумывать и переводить
- сомнительные символы обязаны помечаться `<?>`
- для каждой подзадачи со схемой сохраняется **полная страница** — кнопка
  «Vollständige Seite ansehen» в интерфейсе открывает оригинал

То есть если распознавание где-то соврало, у тебя всегда под рукой картинка
исходной страницы. Формулировки задач читай по ней, если что-то выглядит странно.

## Схемы

Модель возвращает координаты рисунка на странице, скрипт вырезает область в PNG
и вставляет в задание. Координаты приблизительные — область берётся с запасом.
Если вырезалось криво, открывай полную страницу кнопкой.
